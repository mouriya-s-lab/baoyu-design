# Claude 白板

给 DeepSeek Harness 加上 **claude-whiteboard** 技能。让 Agent 画一块白板（"把我们的发布流程画出来"、"把团建的几个方案并排摆一摆"），它会把内容摆在工作区里一个文件夹的白板上（默认是 `designs/<名字>/`，也可以指定别的）：标题、分区、用箭头连起来的方块、表格、便签、手绘图和能操作的小嵌入。写的时候它会启动本地白板编辑器，把链接给你，你可以在编辑器里看着白板一点点成形。

## 怎么用

- 直接用自然语言提要求，或者输入 `/claude-whiteboard` 点名调用这个技能。
- 打开 Agent 给的链接。桌面版里它会在右侧栏的浏览器里打开，和对话并排（设置 → 通用 → 聊天链接打开方式：**应用内侧栏**，默认就是这个）。
- 在白板上可以拖动、缩放、打字、用画笔画，也可以从底部工具栏加分区、便签、形状和贴纸。你改的内容存进 Agent 写的同一个文件夹，你们可以轮流改。
- 留评论：点右上角的评论按钮进入评论模式，点一个元素或一个位置就是评论它，拖一下是框住一块区域。勾上 **Send to Agent** 发出去，Agent 会马上接手，对话空闲时也一样：它改好白板，再在评论里回复你。评论也会以卡片的形式出现在对话里，点卡片上的 **View thread**（中文界面是「查看评论」）会在白板上打开这条评论。这个勾选框只在评论能发给 Agent 时出现；Agent 每次给你白板链接时都会开始等评论。重启应用后，让 Agent 再打开一次这块白板就能恢复。
- **Share** 把白板开放到局域网，每种角色一个链接（编辑、评论、只看），拿到链接的人能实时看到彼此的光标和改动；它的 Export 页可以把整个文件夹下载成一个 zip。**History**（Share 旁边的时钟）列出各个版本。
- 以后要改，让 Agent 修改那块白板所在的文件夹即可。
- 如果工作区自己带了 `claude-whiteboard` 技能（在 `.agents/skills/` 或 `.dsh/skills/` 里），这个工作区会用它自己那份，而不是插件里的。

## 运行方式

白板编辑器是技能脚本在后台启动的一个本地服务（127.0.0.1），这台电脑上的所有白板共用一个，只读写它打开的那些白板的文件夹。用的是桌面版自带的 Node，不需要另外安装任何东西。
